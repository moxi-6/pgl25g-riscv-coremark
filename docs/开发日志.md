这个工程面向《全国大学生嵌入式芯片与系统设计竞赛 2026 FPGA 创新设计赛道》选题一：**基于紫光同创 RISC-V 指令集 CPU 设计**。

当前代码提供一条从 24ysyx E2 到比赛基础任务的最短路径：

1. 用独立模块复习组合逻辑、时序逻辑和模块例化；
2. 用自检 testbench 掌握“先仿真，后上板”；
3. 跑通一个教学用三段流水 RV32I 核；
4. 接入片上 RAM、GPIO 和 UART，形成最小 SoC；
5. 换成紫光同创开发板顶层、PDS 工程和引脚约束；
6. 再做 Cache、异常/中断、分支预测与 CoreMark。

> 当前工程是学习和参赛起步框架，不是最终参赛作品。最终提交还需要结合所选开发板、PDS IP、时序约束和真实性能测试完善。

## 仿真

安装 Icarus Verilog 后，在 PowerShell 中运行：

```powershell
cd fpga_riscv_starter
./scripts/run_iverilog.ps1
```

在 WSL/Linux 中，安装 Icarus Verilog、GNU Make 和 RISC-V 裸机工具链后运行完整回归：

```sh
cd fpga_riscv_starter
sh scripts/run_all.sh
```


## 上板前必须修改

1. 在 PDS 中选择你实际使用的紫光同创器件与开发板；
2. 按原理图填写引脚约束，参见 `constraints/README.md`；
3. 确认 `fpga_top.sv` 的输入时钟频率，并让 `CLOCK_HZ` 与实际一致；
4. 如使用 PDS 的 PLL、片上 RAM 或调试 IP，用厂商 IP 替换教学模型；
5. 用 `software/Makefile` 生成 `firmware.hex`，并在综合工程中加入该文件；
6. 先观察 LED/GPIO，再验证 UART，最后才跑复杂软件。

## 当前 CPU 边界

- 三段控制节拍：取指、执行/访存、写回；
- 支持 RV32I 基础整数指令：LUI、AUIPC、JAL、JALR、分支、Load、Store、OP-IMM、OP；
- 支持 `FENCE` 作为空操作、`EBREAK` 作为仿真停止点；
- 支持写回前递，能处理相邻 ALU 指令和 load-use 相关；
- 数据存储器可通过 `ready` 拉低制造等待周期；
- 检测非法指令和未对齐的指令/数据访问。

比赛高阶项尚未实现：CSR、完整异常/中断、指令/数据 Cache、BTB、乘除法扩展、CoreMark 移植、ILA 性能波形与 PDS 时序收敛。它们已在文档中排好实现顺序。
