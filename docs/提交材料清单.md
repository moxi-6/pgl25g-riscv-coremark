## 四、一键复现

```powershell

```

## 五、边界声明（写进任何材料都成立）

- 不宣称完整特权架构：无 CSR、无中断/异常恢复、ECALL 进 trap 停机。
- CoreMark 的乘除法由软件例程完成，不依赖 M 扩展。
- "最高频率"给出的是时序报告推算值，不是实测运行频率。
- ILA 为单次 512 点触发，用于展示关键内循环，不是完整指令追踪。
- 板卡为非推荐的 PGL25G（22 560 LUT，低于答疑所述推荐区间 50k–200k LUT）。按答疑要求，评审时须主动出示资源与时序证明：LUT 1 840（8.16%）、FF 1 395（4.12%）、DRM18K 16（26.67%）、slack +1.579 ns，来源为 `build/board_release/cpu/coremark/pds_bitstream.log` 与 `timing.rtr`。
- 未使用任何硬核 ARM/NPU 或第三方 IP 核，CPU、外设、ILA 触发逻辑均为自研 RTL，符合答疑"不能使用硬核 ARM、NPU"的限制。
