# 中文横版射击：首个可玩版本

按用户补充的原方案，目标从已有的反应力游戏调整为横版闯关射击。用户要求中文界面，并优先交付可玩版本。本轮继续使用已经实物验收的 ATK-MD0700R 800×480 RGB LCD 通路。

## 操作

任意实体按键开始。KEY0 左移、KEY1 右移、KEY2 跳跃、KEY3 射击；长按 KEY3 可连发。蓝色为玩家，红色为敌人，黄色为子弹。消灭三个敌人后出现右端绿门，走到绿门进入下一关。三关后获胜，生命耗尽则结束，任意键重玩。屏幕无需触摸。

游戏区为左侧 640×480，右侧 160×480 显示中文关卡、生命、得分、剩余敌人数及更新周期/退休指令数。每击杀敌人加 10 分，初始生命 3，受伤后有短暂无敌闪烁。支持八颗子弹和单向可落地平台。三关目前复用同一地图和敌人配置，属于首版可玩流程；滚动地图、更丰富关卡与固定输入性能压测模式尚未实现。

## CPU 与绘图分工

`software/shooter.c` 是实际运行的 RV32I C 程序，负责位置、速度、重力、跳跃、平台落地、敌人巡逻、子弹、碰撞、生命、计分和关卡状态。无硬件游戏状态机替代 CPU 运算。图形模块只合成背景、平台、角色矩形和中文文字。

新增 SoC 参数 `VIDEO_ENABLE`，射击顶层启用，旧 CPU 顶层默认为 0。新增接口：

| MMIO 地址 | 功能 |
|---|---|
| 0x10000044 | 已完成的 LCD 帧数；CPU 据此驱动一次游戏更新 |
| 0x10000050 | 写低字节申请提交，读 bit0 为待提交状态 |
| 0x10000100–0x1000017f | 16 个精灵、每个两字，CPU 写暂存数据 |
| 0x10000030–0x1000003f | 状态、BCD 得分、周期差、退休指令差四字 HUD |

精灵第一字含 enabled bit31、type bits29:28、Y bits24:16、X bits9:0；第二字含 width bits7:0、height bits15:8。CPU 完成整组写入后提交；硬件只在下个帧边界同时发布 HUD 和精灵，活动扫描期间不改动，避免撕裂。

HUD 两组 8 位数为**十六进制**周期差和退休指令差，统计每次输入采样、游戏运算和精灵/HUD 写入；不包含等待下一帧的空转，也不包含计数结果写回后的提交尾部。它们不是 CoreMark 分数或端到端输入延迟。当前像素时钟 25 MHz、帧率约 45.09 Hz，60 Hz 仍为后续目标。

中文使用 Windows 微软雅黑提取的 88 个 16×16 位图字符，本机生成脚本为 `scripts/generate_shooter_font.py`。生成 2048×16 同步 ROM，初始化文件 `rtl/periph/shooter_font.hex` 必须随工程一起打包。界面模板为 `rtl/periph/lcd_shooter_display.sv.in`，生成的 `.sv` 可直接综合，无需运行时操作系统或字体库。

## 验证与产物

- `tb_shooter`：实际 RV32I 固件经过标题页、启动、跳跃、射击、三次击杀、30 分、下一关；检查帧边界原子更新及性能计数非零。耗用 2,904,005 个仿真时钟附近完成该流程。
- `tb_shooter_display`：读取真实同步中文字库，生成完整标题页与游戏画面；检查无未知像素、中文点阵存在。图像 `build/shooter_title.png` 与 `build/shooter_play.png` 为 RTL 渲染测试数据，非实物照片。
- 最终共享 SoC 修改后，额外重跑九项非固件依赖回归通过，日志 `build/shooter_shared_regression.log`。此前 CPU/LCD 阶段完整十六项回归通过；射击版本不将此前全部测试冒充本轮重跑。
- PDS 2022.2-SP4.2、PGL25G/-6/MBG324：5028 LUT、3391 寄存器、18 DRM18K。50 MHz 系统 setup +2.449 ns，LCD 输出 setup +5.126 ns，报告 `All Constraints Met.`。LCD 外部 setup/hold 预算仍沿用初版的暂定 5 ns/2 ns，排线偏斜未实测。
- 30 个 LCD 引脚、3.3V/4mA 属性、源文件、字库、固件和位流哈希审计通过。

位流为 `build/board_release/shooter/shooter/atk_l50_shooter.sbit`，SHA256 `af060a08a578971508ed635c9b975cff9299bb467a909909aef111a6fd7a4aeb`。独立彩条和早先反应力游戏发布包保留。

## 复现

```powershell
& ./fpga_riscv_starter/scripts/build_firmware.ps1 -App shooter -Rebuild
& ./fpga_riscv_starter/scripts/run_shooter_tests.ps1
& ./fpga_riscv_starter/scripts/run_pds.ps1 -Target shooter -Stage Bitstream -ConstraintProfile Vcc33 -FirmwareApp shooter -WorkRoot C:/fpga/riscv_l50/shooter_20261103
python ./fpga_riscv_starter/scripts/audit_lcd.py --target shooter
& ./fpga_riscv_starter/scripts/program_sram.ps1 -Target shooter -FirmwareApp shooter
```

当前接线沿用用户确认的 RGB LCD 和 J28/Bank3 3.3V。仅下载 SRAM，不写 Flash。实板结果见下方续记。
